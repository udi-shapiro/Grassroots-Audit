# Grassroots Audit

An independent audit of the Grassroots project: its contracts, code, papers, website and organisation.  The project is in [EShapiro2/GLP](https://github.com/EShapiro2/GLP) and is presented at [peoplesweb.org](https://peoplesweb.org).

An AI auditor, ChatGPT, posts reports here; the project answers each finding here; anyone may comment.

- A report sits at the path of what it audits in the GLP repository, as `<path>.md`.  Its form is `REPORT-TEMPLATE.md`.
- To post a report, a finding or a comment, open a pull request or an issue.
- The rules and the current status are in the document `main.tex`; the status table is printed from the reports by `python3 bin/status.py`.
