# Calculus (16) against GSC (19)

**27 November 2026.** Removing `met` works for the interaction guarantee now stated in Definition 18(2). Knowledge:2 in §§2.1 and 3.2 agrees with the cited public contract, and the new condition on predicate lifting repairs that part of Proposition 17. The revision changes the strength of the grassroots theorem. Public Knowledge supplies a finite example that separates it from GSC openness. Two other gaps concern the data needed to ground an implication and the evaluation of a negated test.

## 1. What Theorem 21 proves without `met`

Definition 18(2) assumes that persons $p$ and $q$ lie on opposite sides and that $p$ has no stored atom mentioning $q$. The witness in Definition 19 puts such an atom at $p$. It is absent before the act, so the set update changes $p$’s local state. Even if $q$ already records $p$, taking the act changes $q$’s volitional state by consuming its willingness. The new state of $p$ contains another agent and cannot belong to the singleton protocol. This is an interaction. Appendix A then uses the stated extension lemma to obtain a correct run. The missing-record premise supplies the freshness previously supplied by the exclusive predicate.

**Two distinct interaction components, each containing a person, can always coalesce.** By Lemma 24, a person in one component cannot record a person in the other. Definition 18(2) therefore applies. Since the sides can be interchanged, lack of a record in either direction suffices for the two-person argument.

**Public Knowledge distinguishes this from the former guarantee for arbitrary groups that have never interacted directly.** Take exactly three established persons, Alice, Bob and Carol. Carol becomes acquainted with each of the others separately. Then she uses Knowledge:3 twice. The third role in Introduce is read-only and gives no consent. [Pinned Knowledge, clauses 1–3](https://github.com/EShapiro2/GLP/blob/7b68b74c6388135736632957b321ae63503feaf7/calculus/contracts/Knowledge/full-schemas.txt#L6-L9)

| Act after establishment | Agents whose state changes | New knowledge |
| --- | --- | --- |
| Carol and Alice acquaint | Carol and Alice | Carol and Alice know each other |
| Carol and Bob acquaint | Carol and Bob | Carol and Bob know each other |
| Carol introduces Bob to Alice | Carol and Alice | Alice knows Bob |
| Carol introduces Alice to Bob | Carol and Bob | Bob knows Alice |

No step changes both Alice and Bob. At the end every distinct pair knows each other. All three Establish bodies are false, all six ordered Acquaint heads and all six ordered Introduce heads leave the store unchanged, and Definition 6 requires a change. Only one-agent volition changes remain possible. Thus **no extension can contain a first Alice–Bob interaction**. This is a finite safe prefix of a correct run by Extension. It satisfies the revised theorem because its missing-record premise is false for that pair. I replayed the trace and enumerated the 15 final ground instances. [Executable three-person check](./knowledge_three_people.py)

**Paper edit.** Use the distinct-component corollary in the abstract and at the start of §5. State explicitly that direct interaction by two persons in a common component is guaranteed when at least one has no record of the other. GSC (19), Definition 25(1), asks for an extension from *every* finite safe prefix with no prior interaction of the pair. The trace separates the two claims. It concerns the Calculus set interpretation of the public Knowledge clauses. GSC has its own multiset semantics. [GSC coverage finding](https://github.com/udi-shapiro/Grassroots-Audit/issues/169)
