\section{Reports, findings and answers}

\paragraph{A report} is one Markdown file, \dir{<path>.md}, where \dir{<path>} is the path in the GLP repository of what it audits.  It states the auditor, the date and the commit of the GLP repository that was audited, and then its findings, numbered from 1.  The form is \dir{REPORT-TEMPLATE.md}.  A later audit of the same thing amends the same file; the repository's history holds the earlier versions.

\paragraph{A finding} states one fault: where it is, what is wrong, and why.  It carries a severity: high, medium or low.

\paragraph{An answer} is written by the project under the finding it answers, and takes one of two forms: \emph{Corrected}, with the commit that corrects the fault, or \emph{See}, with the place in a paper, a contract or the code that shows the finding does not hold.  An answer points; it does not explain.  A finding with no answer is open.

\paragraph{A finding is a claim} for the project to check.  The project corrects what it finds to be a fault, in the GLP repository or in the paper concerned, and answers here.
